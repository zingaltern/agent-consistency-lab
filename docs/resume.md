# 简历措辞与面试叙事（对齐事实，不写"生产级"）

> 这份文件的作用：保证**简历上的每一句都能被仓库里的某个产物验证**，
> 并且提前标注边界，避免面试时被一句追问击穿。
> 数据出处：`reports/*.json`（汇总入库）、`docs/w2..w7-report.md`。

## 一、项目在简历上的写法（三段式）

### 版本 A（两行，投递用）

> **Agent Runtime 一致性实验台**（个人项目，Python，独立完成）
> 自研 Agent 运行时内核（事件日志 / checkpoint / 审批绑定 / outbox / 上下文压缩），
> 用真实 `kill -9` 崩溃注入与四系统对照评测验证语义；208 个测试、8 份实验报告，
> 全部结论以配对置信区间与 CI 门禁呈现。

### 版本 B（四行，作品集 / 面试自述用）

> - **内核**：扁平 append-only 事件日志（历史改写由数据库触发器物理禁止）+ checkpoint/writes
>   分离提交协议 + 工具自述风险触发的审批门 + outbox 意图行；3.9k 行，零编排框架依赖。
> - **验证**：6 个命名崩溃窗口 × 16 格 × 5 次 = 80 次运行，其中 70 次注入真实 `kill -9`
>   （篡改/长任务对照格按设计不注入），
>   裁判是外部副作用账本而非 runtime 自己的日志；3 个窗口 0 重复副作用。
> - **消融**：4 条技术路线 × 64 个合成场景 × 2 个推理器人格 = 1536 次运行，
>   证明"证据覆盖"是一阶项、"审批门"的价值在把人拉进回路；同场景下 LangGraph 95 行
>   vs 自研 340 行胶水，能力等价，差异在崩溃一致性与工具自述风险。
> - **工程**：CI（3.11/3.12 双版本 + 门禁，含"实验假设自检"）+ 提供一键复现全部结论的命令流水线。

**避免的写法**：不写"生产级 Agent 平台"、不写"高并发"、不写"提升了 X%"（没有真实流量，
任何百分比都是合成环境的相对值）。

## 三、面试官可能问的问题 → 用哪份数据回答

| token 超限怎么办？ | 三级：卸载（纯赚，-66%）> 压缩（拿钱买可用性，+79%）> 拒绝调用并报错；阈值扫描显示 0.70–0.95 成本不可区分 | `docs/w7-report.md` |
| 链路断了怎么办？ | 事件日志折叠 → 未闭合调用重跑 → pending 意图先探针对账；16 格 × 5 次 = 80 次运行的崩溃矩阵（70 次真实 SIGKILL） | `docs/w2-crash-windows.md` |

| QPS / 延迟多少？ | **没有真实流量**，我不编这个数。能给的是一次任务的成本（$0.005–0.012）与步数（3.4），以及本地墙钟仅供参考 | `docs/HANDOFF.md` §三 |
| 幻觉怎么解决？ | 在我这个场景里答案是"证据门槛"：取证不足就不下结论（honest 人格的行为），以及审批门拦住"证据不足时的激进动作" | `docs/w5-report.md` §八 |

## 四、必须主动交代的边界（写在简历末尾或面试开头）

1. **场景与模型都是合成的**：没有真实流量、真实事故数据或公开 Postmortem 数据集；
   分类学参考公开故障模式。因此所有"正确率"是**架构在受控条件下的表现**，不是线上效果。
2. **模型是确定性脚本**：可以测成本、缓存与一致性，**测不了回答质量**。
3. **崩溃结论只对 `kill -9` 成立**：掉电语义（`synchronous=NORMAL` 下可能丢最后一个事务）未覆盖。
4. **两套样本量口径不要混引**：W2–W4 每格 n=5（点估计），W5–W7 n=192（区间 + 配对差值）。
5. **评审与审计都是 AI 扮演的**：五路审计逐条核到 repo/文档/JD 证据，但它们是"对抗性评审"，
   不是真人专家意见。

## 六、如果被问到"这个项目的局限是什么"

按这个顺序答，它比任何优点都更能证明你知道自己在做什么：

1. **没有用户、没有流量**——所有指标都是合成环境里的相对比较；
2. **规则引擎支配 LLM 路线**（full-rule 反事实 100% 正确、更便宜）——
   说明我的场景集不满足"agent 该上场"的条件（步骤无法预先枚举）；
3. **审批门的价值依赖人**：橡皮图章下红线率与无门系统完全相同；
4. **掉电、并发（租约）、artifact GC 都没做**，边界写在 `docs/HANDOFF.md` §五。
